## Public installation smoke

A new, out-of-checkout Windows/Python 3.14 environment installed
`donewitness==0.2.0` from the public PyPI index. Version, installed module identity,
and dependency checks passed. The example checkout was cloned from `v0.2.0`, and
its commit matched the released SHA.

Chromium provisioning used an initially empty, explicitly isolated browser directory.
The first `python -m playwright install chromium` wrapper timed out after **900
seconds**. At resumption, that directory contained the downloaded managed components;
repeating the same installation command with the same isolated path exited 0.
The initial uninterrupted provisioning attempt remains a failure. No shared browser
cache was substituted, and this record does not claim a clean uninterrupted download.
