# DoneWitness v0.2.0 candidate

This is the second-release candidate, not a publication announcement.

## Changes

- Plan v3 adds text, input-value, count, and hidden/absent assertions to deterministic
  browser verification. Plan v1/v2 behavior and digests remain unchanged.
- `donewitness validate --plan PATH` checks format and digest without starting an
  application or browser. It never claims the application passed.
- Help/version defer execution dependencies. Startup is measured with
  `python scripts/benchmark_cli.py`; see release evidence for results and limits.
- A concise quickstart and expense example demonstrate incorrect totals and fake
  saves using the same acceptance plan as the working application.
- Interrupting application startup now preserves an incomplete UNKNOWN receipt,
  including Docker startup before the process adapter returns.

## Upgrade

Existing v2 plans need no edits. To use new assertions, review the criteria and
explicitly select schema version 3. Old clients reject v3. Receipt v1–v4 inspection,
manifest v1, machine summary v1, exit codes, and local/Docker/revision boundaries
are retained. No runtime dependency is added.

Install this checkout with `python -m pip install -e ".[dev]"`. After publication,
the package command will be `python -m pip install donewitness==0.2.0`.

## Validation and limits

See [release evidence](v0.2.0-evidence.md). Example persistence is browser
localStorage, not a production database. Fault injection demonstrates specific
covered defects, not market demand or comprehensive coverage. CLI startup
improvements do not imply faster browser execution.
